# Electricity Consumption Prediction

## About the Project
This project uses Machine Learning to predict electricity consumption based on different input features.

## Objectives
- Analyze electricity consumption data.
- Perform data preprocessing and exploratory data analysis.
- Train machine learning models.
- Compare model performance.
- Predict electricity consumption using new input values.

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

## Machine Learning Models
The project evaluates different machine learning models to identify the best-performing model.

## Project Workflow
1. Data collection
2. Exploratory Data Analysis (EDA)
3. Data preprocessing
4. Model training
5. Model evaluation
6. Prediction

## How to Run
Open the notebook in Google Colab and run the cells step by step.
